# Fraud Detection for E-commerce and Bank Transactions

A machine learning project that detects potentially fraudulent transactions in e-commerce and banking data. It includes data preprocessing, feature engineering, model training, evaluation, and tools for exploring fraud detection results.

## Features
- Data cleaning and preprocessing
- Feature engineering
- Machine learning model training and evaluation
- Fraud prediction API
- Interactive dashboard for exploring results

## Technologies
Python, Pandas, Scikit-learn, XGBoost, Jupyter Notebook, and Streamlit.

## Getting Started

1. Clone or download this repository.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Follow the instructions in the project notebooks or run the available application scripts.

**Note:** Required datasets and model files must be available in the locations expected by the project.

## Purpose

The project explores how machine learning can help identify suspicious transactions and support financial fraud prevention.
